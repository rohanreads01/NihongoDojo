## Nihongo Dojo – Installation Guide

### Prerequisites

- Windows 10 or later  

---

### Step 1: Download the ZIP

1. Go to the [Nihongo Dojo releases page][releases]  
2. Click **Download ZIP** and save it (e.g. to `Downloads/NihongoDojo.zip`)  

Alternatively, download directly from [Google Drive](https://drive.google.com/drive/folders/1V4kyBRlvjxz3OS6en_L8vZl5h7uqHKQo?usp=sharing )

---

### Step 2: Unblock the ZIP file

Windows may block files “from the Internet,” which can prevent the app from running:

1. Open **File Explorer** and locate `NihongoDojo.zip`  
2. Right-click → **Properties**  
3. In the **General** tab, check **Unblock** at the bottom  
4. Click **Apply** → **OK**

---

### Step 3: Extract the ZIP

1. Right-click `NihongoDojo.zip` → **Extract All…**  
2. Choose a folder (e.g. `C:\Users\<you>\Downloads\NihongoDojo`)  
3. Click **Extract**

---

### Step 4: Run Nihongo Dojo

1. Open the folder you just extracted  
2. Double-click **NihongoDojo.exe**  

The app will launch, start its local API server in the background, and open the UI.
